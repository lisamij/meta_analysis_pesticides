# README

**Scripts that run the analyses**

The scripts here used the functions in the R folder to run the analyses and create the tables and figures used in the manuscript.

- One_method_analysis: Allows to run the full analysis for one set of parameters. The parameters to chose are: the variance method, the inclusion of the cell lines, the running of the leave one out analysis, the running of the profile plots, the imputation method, the width and height of plots 

- All_methods_analysis: ALlows to run the analysis to compare all the variance/imputation/cell lines combinations. Parameters to determine: leave one out analysis, running of the profile plots and use of robust function
 
- EFSA_analysis: Allows to run the EFSA analysis
